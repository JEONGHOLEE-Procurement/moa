# MOA (모아) — 해외 거주 한인 사업자를 위한 통합 홍보 관리 대시보드

인스타그램·유튜브·틱톡·X·페이스북·네이버·구글·카카오까지, 흩어진 홍보 채널을
하나의 대시보드에서 관리한다. 발행·예약·통합 인박스·리뷰·예약 관리·광고 ROI까지.

> 타깃: 해외에서 직접 뛰는 1인/소규모 한인 사업자 (서핑샵 · 한인숙소 · 한식당 · 카페)

## 실행

```bash
npm install
npm run seed     # 데모 데이터 시드 (최초 1회, 기동 시 비어있으면 자동)
npm start        # http://localhost:3500
```

- `/`          랜딩(소개) 페이지
- `/dashboard` 대시보드

## 기능 (모두 실제 동작)

| 섹션 | 동작 |
|---|---|
| 개요 | KPI 6종 · **생산성(아낀 시간) 패널** · 채널별 성과 · 예약 게시물 · 최근 메시지 |
| 콘텐츠 작성 | 한 번 작성 → **여러 채널 동시 발행** · 이모지 · 실시간 미리보기 · 지금발행/예약발행 |
| 캘린더 | 월간 그리드 · 예약/발행 이벤트 · 클릭 상세 · 예약 삭제 |
| 통합 인박스 | 8채널 댓글·DM 통합 · 필터(안읽음/미답장/채널별) · 답장 · 감정 표시 |
| 리뷰 | 구글·네이버 리뷰 · 평점 분포 · 답변 등록 |
| 예약·문의 | 상태별(신규/확정/완료/취소) 관리 · 상태 변경 · 신규 예약 추가 |
| 분석 | 채널 성장 멀티라인 차트(팔로워/도달/참여) · 광고 ROAS·CTR 표 |
| 채널 연결 | 채널 연결/해제 토글 |

모든 상호작용은 SQLite에 실제로 저장된다(작성·답장·상태변경·추가·토글).

## 생산성 지표

반복 작업 대비 아낀 시간을 추정해 개요와 랜딩에 노출한다.
멀티 채널 발행(채널당 7분), 예약 발행(5분), 통합 인박스(건당 3분), 리뷰 응대(4분)로 계산하며,
**쓸수록 숫자가 늘어난다** — 실제 사용 데이터에서 파생되기 때문.

## 데이터 모델 (SQLite · `moa.db`)

`business · channels · metrics_daily · posts · post_channels · inbox · reviews · reservations · ads`

## 구조

```
db.js         스키마
seed.js       데모 사업장(발리 한인 서프 게스트하우스) 시드 — 멱등
server.js     Express REST API (포트 3500)
public/
  index.html      랜딩
  dashboard.html  대시보드 셸 + 스타일
  dashboard.js    8개 섹션 로직 (의존성 없는 vanilla JS)
  moa.css         디자인 토큰 (Pretendard · 라벤더/퍼플/민트)
```

## 경계 (실제 연동)

데모는 채널 연결을 토글하며 대시보드 동작을 체험하는 수준이다.
실제 서비스는 각 플랫폼 공식 API(OAuth)를 거쳐 연동해야 하며,
채널별 데이터/발행은 그 커넥터가 이 데이터 계층을 채우는 구조로 확장한다.
